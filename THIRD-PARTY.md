# Créditos y terceros

Este repo solo contiene scripts y ajustes. Las aplicaciones **no se redistribuyen**: se instalan desde `winget` o desde el release oficial de cada proyecto.

| Qué | Origen | Licencia |
|---|---|---|
| Tema de Flow Launcher *Catppuccin Mocha* (`config/flow/Themes`) | [catppuccin/flow-launcher](https://github.com/catppuccin/flow-launcher) | MIT |
| Paleta Catppuccin Mocha (Terminal, fondo) | [catppuccin](https://github.com/catppuccin/catppuccin) | MIT |
| Plugin Clipboard+ | [Jack251970/Flow.Launcher.Plugin.ClipboardPlus](https://github.com/Jack251970/Flow.Launcher.Plugin.ClipboardPlus) | ver su repo |
| Plugin Window Walker | [taooceros/Flow.Plugin.WindowWalker](https://github.com/taooceros/Flow.Plugin.WindowWalker) | ver su repo |
| Plugin Windows Settings | [Flow-Launcher/Flow.Launcher.Plugin.WindowsSettings](https://github.com/Flow-Launcher/Flow.Launcher.Plugin.WindowsSettings) | ver su repo |
| Plugin Colors | [Flow-Launcher/Flow.Launcher.Plugin.Color](https://github.com/Flow-Launcher/Flow.Launcher.Plugin.Color) | ver su repo |
| Plugin Search Unicode & Emoji | [blueset/flow-search-unicode](https://github.com/blueset/flow-search-unicode) | ver su repo |
| Fondo `assets/wallpaper.jpg` | generado para este repo con la paleta Catppuccin | MIT (como el resto) |

Los plugins se descargan al instalar, con versión fija (`plugins.json`) y comprobación de SHA256.
